# Gothic 3 VR 0.22.5 — native Sneak weapon restriction; Run/Sprint only

The 0.22.4 weapon-selection intervention is removed. OnPlayerSelectWeapon keeps its original native entry and registered pointer, including the native refusal in Sneak. The automatic release of Sneak, temporary Stand and equipment suspension/resumption are removed. NativeArmedSneak is restored exactly to its 0.22.3 source; entering Sneak with an already drawn weapon and the existing Murder qualification remain. The radial captures locomotion/buttons while preserving an already selected native Sneak, so its weapon command cannot bypass the native restriction by briefly leaving Sneak. Real GUI/world suspension still releases owned inputs. Y in the radial remains a page command.

L3 retains its accepted tap toggle: on selects native Sprint, off selects normal Run. Left grip remains free for support; double-tap Y still toggles Sneak. No Walk mode is offered by L3.

The native OnPlayerWalk script sends its press to Walk when the actor is standing or braking, and to Sprint otherwise. Previously L3 toggled the same input immediately, letting its activation from idle become persistent Walk. The plugin now starts in ordinary native Run and waits until native standing/braking ends before sending the original Sprint press. Neutral or braking releases that input; the L3 preference is retained and resumes once movement is ready. This removes the idle Walk branch without forcing Sprint or bypassing native stamina/skill/refusal handling.

As a fallback, a delayed native wished Walk3 is normalized to Run4 before original ProcessMovements. Native wished Sprint5 and native refusal/exhaustion results are left alone. The SDK private wished-mode offset0xac is verified against the exact native SetWishedMovementMode store instruction. Native Sneak retains its own slow pace; normal locomotion has only Run/Sprint. No direct velocity, motor, animation stop or speed multiplication is added. Logs include vr_run_sprint_input with selected/pressed/standing/braking context.

71/71 tests pass, including replay of L3 activation from stand and brake, delayed Walk3 fallback, native Sprint/refusal preservation, native wished-member instruction verification, Sneak held during radial pages, double-tap and reset chords, and existing GPU/stereo/render restoration/ranged/combat/progression/lifecycle checks. The launcher is unchanged from0.22.4; its15-page layout validation and captures are retained with explicit provenance. Native game DLLs, accepted bow/crossbow behavior, calibrated tracking, rigid grips and sprint/jump opacity correction are unchanged. Installation backs up binaries and preserves current user INI bytes. Live acceptance of the native weapon restriction and L3 Run/Sprint still requires the user's test; the game is not launched unattended.
