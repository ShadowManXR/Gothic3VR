## Authenticity

Use the official download channels and compare release checksums. Releases that
include a detached signature can be verified with the published release key using
[the verification instructions](docs/VERIFY-RELEASES.md). A signature authenticates
the checksum manifest; it is not a Windows Authenticode certificate or an assurance
that a build is free of bugs. Existing tags and executables are not retroactively re-signed.
