charcoal/blue-grey Gothic landscape. Quiet negative space sits beneath the

prompt is retained in `tools/assets/launcher-background-prompt.txt`; the final

`0F194285DA5489630301C4AC922E4E5F0EA77054334E6852198854DE74615668`).

changes. The normal-size and compact UI checks both passed and the integrated
