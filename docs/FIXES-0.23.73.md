# 0.23.73 - Restore character focus and L3 Sprint; quick-heal chord

- Characters use the pre-0.23.72 interaction rating and native priority/comparison path. A native-selected character is retained rather than displaced by compact-object ranking. The improved object scoring remains available for chests, offerings and other non-character targets, with the same reach and native LOS gates.
- **Tap L3** to select Sprint until movement stops. Releasing the joystick to stop clears Sprint; starting again uses ordinary Run until another L3 tap. A second tap can also return to Run. This restores the previous controller-toggle helper; movement directions, speed and native stamina eligibility are unchanged.
- **Left primary/index trigger + left lateral grip/squeeze** invokes native quick heal once per chord activation. Either button by itself does not heal. Analog release hysteresis prevents small pressure fluctuations from consuming multiple potions. Release either button and form the chord again for another potion. The lateral grip by itself remains weapon support.
- Menu, radial, recenter, focus loss and stale input suspend the combination. L3+R3 still recenters. Native quick-heal inventory/animation rules remain in charge; no direct health or inventory mutation is introduced.

Static third-person conversations and trade-only right-grip single-item transfers from 0.23.72 are retained. Launcher instructions are updated in English. Existing graphics/runtime configuration and calibration are preserved.
